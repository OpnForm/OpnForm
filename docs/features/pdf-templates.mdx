---
title: 'PDF templates'
description: 'Create reusable PDF layouts and duplicate them within your workspace.'
---

You can create PDF documents from submissions using **PDF Templates** on your form dashboard. Upload a PDF or choose **Add template → Create from scratch**, then position text, images and mapped fields in the editor.

## Duplicate a template

1. Open your form's **PDF Templates** tab.
2. Open the template's menu and choose **Duplicate template**.
3. Enter a name and select the destination form. You can choose the current form or another form in the same workspace.
4. When copying to another form, review the field mappings. Unique matches with the same name and type are preselected. Choose a destination field or **Skip this field** for every remaining field. Computed variables can also be mapped.
5. Select **Duplicate template** to open the new copy in the editor.

<Note>
You need edit access to both forms. Skipped field zones are excluded from the copy; their static text labels remain. Special fields such as the submission ID use the destination form's submission data automatically.
</Note>

The copy keeps the page order, text, images, filename pattern and branding setting. Its PDF file is independent, so editing or deleting either template does not affect the other. Duplicating a template does not change email attachments or the form's selected download template; select the copy separately where needed.

## Edit pages and zones

Use **Add Zone** to insert a form field, computed variable, static text or image. New zones always start inside the page. Drag and resize zones to adjust your layout.

The **Duplicate page** control in the left sidebar copies a page inside the current template. Use **Duplicate template** from the template list when you need a separate document.

Save your changes before opening **Preview**. The preview includes sample submission values when submissions are available.
