The Composer changes and direct npm package changes are recorded in [versions.json](../security/dependencies-2026-10-23/versions.json). Composer resolution targets PHP 8.3.36 so resolving with a newer local PHP cannot silently select PHP 8.4/8.5-only packages. `composer check-platform-reqs` still verifies the actual runtime and extensions. CI and Docker installations no longer ignore platform requirements. The locked `lcobucci/clock` library, used by JWT, rejects PHP 8.5; the worktree selector skips that runtime instead of bypassing Composer's platform check.

The Nuxt migration retains the existing source directory. UI ButtonGroup becomes FieldGroup; Sentry build options use the v11 shape. The GTM integration uses the underlying Vue library because its former Nuxt wrapper requires Nuxt 3. Amplitude moves to the Browser SDK, preserving named events, user properties and attribution while explicitly disabling new automatic event collection. Nuxt UI locale chunks load on demand with request-local SSR state and the previous locale fallback behavior. Form initialization awaits its language before rendering so the lazy message catalogs and UI locale agree during hydration. The public bundle budget remains 420 KiB gzip. The checked-in minified embed SDK is regenerated with the upgraded esbuild and matches the tested production asset.

## MCP migration and separate advisory checks

MCP 1.x invokes tools through `ToolInvoker`. The application adapter keeps the tool-level OAuth challenge in `_meta["mcp/www_authenticate"]`. Dynamic registration retains Passport 12 compatibility after MCP refreshes its client model. The application owns one named, throttled registration route.

- [GHSA-mx2h-h55v-pm44](https://github.com/laravel/mcp/security/advisories/GHSA-mx2h-h55v-pm44): deceptive loopback redirects are rejected by regression tests and an HTTP smoke check.
- [GHSA-m25c-38v7-94p8](https://github.com/laravel/mcp/security/advisories/GHSA-m25c-38v7-94p8): a regression test prevents unadvertised OAuth resource metadata from receiving a client secret. Application code serves MCP; it does not configure MCP client OAuth routes. The test also checks the upgraded library's client behavior.

These advisories were absent from the initial Composer scan. `scripts/check-security-versions.mjs` supplements registry scanners with explicit lock floors. Tests preserve JWT, Sanctum and Passport separation, workspace authorization, PKCE, consent, refresh and revocation.

## Reproducing validation

Use a patched PHP 8.3 or 8.4 runtime compatible with the lock and Node 24.22.1 (`client/.nvmrc`). Install with `composer install` in `api/` and `npm ci` in `client/`. Run `composer check-platform-reqs` after installation. The existing Codex worktree scripts provide isolated database, API and UI ports.

```sh
# api/
composer validate --no-check-publish
composer check-platform-reqs
composer --no-plugins --no-scripts audit --locked --format=json
composer --no-plugins --no-scripts audit --locked --no-dev --format=json
vendor/bin/pint --test
vendor/bin/phpstan analyse --memory-limit=2G --no-progress
mkdir -p storage/framework/views-security-tests
VIEW_COMPILED_PATH="$PWD/storage/framework/views-security-tests" php -d memory_limit=1G vendor/bin/pest

# client/
npm audit --package-lock-only --ignore-scripts --json
npm audit --package-lock-only --ignore-scripts --omit=dev --json
npm run lint
npm run test -- --run
npm run test:email-events
npm run test:ssr-cache
npm run build
npm run test:ssr-cache:built
npm run test:e2e
```

`artisan test` is not registered because this repository excludes Collision/Pest's providers from package discovery. The Pest entry point exercises the same Laravel tests directly.

For browser tests, the CI artifact includes the raw Nuxt client manifest at `.output/qa/client.manifest.mjs`; local builds can use `.nuxt/dist/server/client.manifest.mjs`. The test setup reserves capacity in the real anonymous and authenticated API buckets, waiting instead of disabling the limiters. The production build is fast enough to exhaust either bucket during a full suite. Browser interaction also waits until Vue has attached its event handlers to SSR inputs. The shared sliding transition keeps a stable element around its slot to avoid SSR fragment hydration mismatches with the upgraded Vue compiler. The bundle checker respects `NUXT_BUILD_DIR` so isolated worktree checks cannot accidentally measure an older default build.

The upload smoke test caught an existing first-upload edge case with a null initial value: FileInput tried to fetch its own temporary storage key as a URL and replaced the local file. The watcher now preserves a file it already holds; a unit regression test first reproduced the failure.
