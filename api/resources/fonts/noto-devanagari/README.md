# Noto Sans Devanagari and Latin fallback

Original static fonts from Noto Fonts, downloaded 2026-10-17:
- https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSansDevanagari
- https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans

The unmodified `NotoSansDevanagari-Regular.ttf` supplies Indic glyphs and shaping
tables; `NotoSans-Regular.ttf` supplies Latin letters for mixed text areas.
Both are distributed under the SIL Open Font License 1.1 in OFL.txt.
Embedding/subsetting does not change the licence of generated PDFs.
