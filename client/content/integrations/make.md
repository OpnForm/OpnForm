## Automate with Make

Make helps you turn OpnForm submissions into visual automation scenarios. Send data to other apps, transform responses, trigger notifications, and coordinate multi-step workflows.

## Setup guide

1. Open Make and create a scenario for new OpnForm submissions.
2. Connect OpnForm through the available app or webhook trigger.
3. Map submission fields into your scenario modules.
4. Run a test and activate the scenario.

## When to use it

Use Make when your form submissions need visual branching, multi-step automations, app-to-app routing, or data transformation before reaching another tool.
