## Automate workflows with n8n

n8n helps you turn OpnForm submissions into custom automation workflows. Send responses to apps, internal APIs, databases, CRMs, and team tools with visual workflow logic.

## Setup guide

1. Navigate to **OpnForm > Integrations** in your form editor.
2. Select **n8n** or use a webhook trigger from your n8n workflow.
3. Map submission fields into your workflow steps.
4. Test the workflow and activate it.

## When to use it

Use n8n when you need flexible automation, self-hosted workflows, custom API steps, or multi-step logic around each form submission.
